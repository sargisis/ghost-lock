# ghost-lock

Аудит и укрепление iPhone **поверх Lockdown Mode**. Работает локально, ничего не отправляет в сеть.

## Честно о том, как это устроено

iOS — закрытая система: **без джейлбрейка невозможно** поставить в телефон фонового
демона, который стартует при включении, или «дописать» что-то внутрь Lockdown Mode.
Поэтому ghost-lock построен на легальных механизмах:

| Компонент | Где работает | Что даёт |
|---|---|---|
| `audit` (краш-логи + IOC-скан) | ПК, по проводу | Поиск следов шпионского ПО класса Pegasus/Predator (методика Amnesty MVT), джейлбрейк-артефактов, стalkerware, фишинга |
| `dns_shield.mobileconfig` | Телефон, постоянно | Зашифрованный DNS-over-HTTPS с блокировкой малвари/фишинга на уровне резолвера. **Работает всегда, переживает перезагрузку** — это ближайшая легальная альтернатива фоновому сервису |
| `hardened.mobileconfig` | Телефон | Жёсткие ограничения поверх Lockdown Mode (часть ключей требует режима «Под контролем») |
| udev-правило | ПК | Авто-запуск аудита при подключении айфона кабелем |

Lockdown Mode остаётся включённым — ghost-lock его не трогает и дополняет.

## Быстрый старт

```bash
sudo apt install libimobiledevice-utils   # если ещё нет

python3 ghost_lock/ghost_lock.py doctor   # проверка окружения
python3 ghost_lock/ghost_lock.py devices  # список подключённых айфонов
python3 ghost_lock/ghost_lock.py audit    # полный аудит + HTML-отчёт
```

При аудите разблокируй айфон и подтверди «Доверять этому компьютеру».

Отчёты складываются в `~/.local/share/ghost-lock/reports/`.

## Установка щита на телефон (2 минуты)

```bash
python3 ghost_lock/ghost_lock.py profiles --serve
```

Затем на айфоне в Safari открой показанный URL (`dns_shield.mobileconfig`),
Настройки → Загруженный профиль → Установить → перезагрузка.
Проверка: Настройки → Основное → VPN и управление устройством → DNS.
Повтори для `hardened.mobileconfig`.

> iOS покажет «Профиль не подписан» — нормально для самодельного профиля.

### Пресеты DNS-щита

| Пресет | Блокирует | Фолбэк |
|---|---|---|
| `family` *(по умолчанию)* | 18+, малварь, фишинг, proxy/VPN-обходчики, mixed-content + SafeSearch (CleanBrowsing) | plain-DNS CleanBrowsing |
| `cf-family` | малварь + 18+ (казино НЕ блокирует) | 1.1.1.3 / 1.0.0.3 |
| `security` | только малварь и фишинг, контент не трогает | 1.1.1.2 / 1.0.0.2 |
| `nextdns --nextdns-id <ID>` | что включишь в панели my.nextdns.io (есть категория Casino/Gambling) | 8.8.8.8 |

```bash
python3 ghost_lock/ghost_lock.py profiles --serve --preset family
```

**Почему интернет не сломается:** в профиле прописан `ServerFallback` — обычные
DNS-серверы того же фильтрующего вендора. Если DoH-сервер недоступен, iOS молча
переходит на них: политика фильтрации сохраняется, сайты открываются. Профиль
снимаем в любой момент (Настройки → VPN и управление устройством).

Для блокировки именно казино выбирай `family` или `nextdns` с категорией
Gambling в панели.

## Автозапуск при подключении по USB (glock-watch)

Go-демон слушает kernel-события USB через netlink и сам запускает аудит,
как только айфон воткнули в кабель. Ставится как пользовательский
systemd-сервис, стартует при включении компа:

```bash
./deploy/install_watch.sh
```

Управление:
```bash
systemctl --user status glock-watch     # что делает прямо сейчас
journalctl --user -u glock-watch -f     # живые логи аудитов
systemctl --user stop glock-watch       # остановить
```

Чтобы сервис поднимался до логина: `sudo loginctl enable-linger $USER`.
Старый udev-вариант (`deploy/install_udev.sh`) не нужен вместе с демоном —
иначе аудит запустится дважды.

## Обновление базы IOC

```bash
python3 ghost_lock/ghost_lock.py update-ioc
```

Тянет доменные индикаторы из официальных фидов AmnestyTech
(Pegasus: ~1400 доменов, Predator/Cytrox: ~340) и сливает с локальной базой.
Стартовая база + фиды = **~1800 доменов** шпионской инфраструктуры.

Формат ручной записи: `{"value": "домен", "weight": 1-10, "source": "отчёт"}`.
Скоринг: `<3` чисто · `3–14` подозрительно · `≥15` критично.

## Что ещё умеет audit

- **Скан установленных приложений** (`ideviceinstaller`) против bundle-id
  stalkerware (mSpy/FlexiSPY/CocoSpy/uMobix/EyeZy + эвристики keylogger/spyware)
- **Проверка свежести iOS** против api.ipsw.me: устаревшая версия =
  известные эксплойты остаются рабочими → попадёт в отчёт первой строкой

## Про контроль трафика — честно

Глубокая инспекция трафика внутри айфона требует своего VPN-приложения
(NetworkExtension) и Apple Developer аккаунта — это вне scope. Доменный
контроль закрывает DNS-щит (см. пресеты выше).

## Ограничения

- Аудит видит краш-логи и метаданные устройства, но не содержимое телефона
  (для глубокой форензики нужен зашифрованный бэкап и MVT).
- DoH-щит блокирует домены на уровне DNS; трафик мимо DNS (зашитые IP) он не видит.
- Часть ключей hardened-профиля применяется только на устройствах «Под контролем»
  (Apple Configurator на Mac).
